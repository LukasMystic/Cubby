# Joey & Mia Story Data

Folder ini hanya berisi data JSON untuk interactive branching story Joey & Mia.

Aman diletakkan di repository sebagai data karena tidak mengubah file aplikasi yang sudah ada.

Entry point:
- main.json = peta/router cabang
- opening.json = awal cerita
- 1.json, 2.json, 3.json = cabang pertama
- 1A/1B/1C, 2A/2B/2C, 3A/3B/3b(i)/3b(ii)/3C = cabang lanjutan
